# Sample Outputs

This folder contains curated example outputs that are intentionally committed to the repository.

## Current Sample Set

- [test1/](test1): outputs copied from the validated real-audio run of [file/test1.mp3](../file/test1.mp3)

## What Stays Here

- Human-reviewable transcript artifacts
- Small metadata files that explain where the sample came from

## What Stays Out

- Runtime state under `.minutes-data/`
- Normalized WAV files
- Per-speaker scratch clips and temporary segment folders
- Model caches and other machine-local outputs
